# 轻练 · 极简健身营养管理 PWA

纯前端移动端优先 PWA：食物热量查询、饮食与运动记录、每日热量目标与可视化。
无后端、无 AI、无任何付费 API，所有数据仅存储于浏览器 `localStorage`。

## ✨ 功能

- **账号系统**：本地注册/登录；注册时必填昵称、性别、身高、体重（选填年龄与实测基础代谢）；登录状态保持；测试账号 `A / AAAAAA`。
- **头像**：从手机相册选择照片，自动裁剪为圆角方形头像。
- **身体档案**：一个账号多档案（自己/家人）；Mifflin-St Jeor 公式计算 BMR（或使用实测值）→ 活动系数 → 目标系数 → 每日目标与宏量建议。
- **食物数据库**：内置 70 种常见食物，支持 克/个/杯/勺/毫升 等单位换算，支持自定义食物。
- **运动数据库**：内置 44 种运动（有氧/力量/柔韧恢复/日常活动），含 MET 值；消耗 = MET × 体重 × 小时。
- **运动计时器**：开始/暂停/继续/结束，记录总用时、运动时长、休息时长、组数、实时预计消耗。
- **数据可视化**：7/30 天摄入与消耗柱状图、体重折线图、当日宏量营养素比例（Chart.js 本地打包）。
- **PWA**：可安装到手机主屏，离线可用（依赖全部本地打包，Service Worker 预缓存）。

## 🚀 部署（免费静态托管，三选一）

Service Worker 需要 HTTPS，以下平台均免费支持。

### GitHub Pages
1. 新建仓库，上传本目录全部文件。
2. Settings → Pages → Source 选择分支，保存。
3. 打开 `https://<用户名>.github.io/<仓库名>/`。

### Vercel
1. 注册登录 → **Add New → Project** → 导入仓库。
2. Framework Preset 选 **Other**，Deploy。

### Netlify
1. 注册登录 → **Add new site → Deploy manually**。
2. 把本目录整个拖入上传。

> 本地预览：任意静态服务器（`npx serve .` / VS Code Live Server）即可；`file://` 直接打开也能运行（仅离线缓存不生效）。

## 📱 如何安装到手机（PWA 安装教程）

### iPhone（iOS / Safari）
1. 用 **Safari** 打开已部署的网址（如 `https://xxx.netlify.app`）。
2. 点击底部「分享」按钮（方框 + 向上箭头）。
3. 向下滑动菜单，点击 **「添加到主屏幕」**。
4. 确认名称「轻练」，点击右上角 **「添加」**。
5. 桌面出现「轻练」图标，点开即可全屏使用，**断网也能用**。

### Android（Chrome）
1. 用 **Chrome** 打开已部署的网址。
2. 点击右上角 **⋮ 菜单**。
3. 点击 **「安装应用」**（或「添加到主屏幕」）。
4. 按提示确认，桌面出现「轻练」图标。

> 提示：安装后建议每隔一段时间打开一次联网刷新，让 Service Worker 缓存更新到最新版本。

## 🔒 数据说明

- 所有数据仅存本机 `localStorage`，**不发送任何网络请求**。
- 存储结构带 `version` 字段；账号（`ql_accounts`）与档案/记录（`ql_users` / `ql_records`）分离。
- 「我的 → 数据与账号」支持导出/导入 JSON 备份。

## 🧭 数据计算公式

- BMR（Mifflin-St Jeor）：男 `10×体重 + 6.25×身高 − 5×年龄 + 5`；女 `… − 161`；如有实测值则优先使用
- 每日目标 = BMR × 活动系数（1.2 / 1.375 / 1.55 / 1.725）× 目标系数（减脂0.8 / 增肌1.1 / 保持1.0）
- 宏量（克）：蛋白质 = 目标 × p% ÷ 4；脂肪 = 目标 × 25% ÷ 9；碳水 = 目标 × 剩余% ÷ 4
- 食物换算：`热量 = 每100g热量 × 克数 ÷ 100`
- 运动消耗：`kcal = MET × 体重(kg) × 时间(小时)`
- 首页「剩余可摄入」= 目标 − 已摄入 + 已消耗（运动可抵扣）
